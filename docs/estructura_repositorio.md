# Estructura del repositorio

Este repositorio está organizado por lenguaje de programación. Cada lenguaje contiene tres versiones de la aplicación:

1. `version1_soap`: cliente SOAP que consume el servicio público `NumberConversion`.
2. `version2_soap_traduccion`: cliente SOAP más traducción del resultado de inglés a español.
3. `version3_web_espanol`: aplicación web propia que convierte un número a letras en español.

La estructura facilita el uso de ramas de Git por lenguaje, por ejemplo:

- `feature/php`
- `feature/node`
- `feature/dotnet10`
- `feature/golang`
- `feature/java`
- `feature/cpp`
- `feature/ruby`
- `feature/perl`
- `feature/rust`
